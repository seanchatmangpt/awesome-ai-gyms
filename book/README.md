# AI Gym Pattern Language

This directory contains the mdBook source for **A Pattern Language for AI Gyms**.

Build locally with:

```bash
mdbook build book
```

Serve locally with:

```bash
mdbook serve book --open
```

The book is intentionally separate from the generated repository `README.md`. The README remains a projection of the canonical gym registry; this book is the architectural pattern language for designing, manufacturing, executing, evidencing, and governing gyms across the wider ecosystem.

The current first edition contains **64 patterns** across eight families.
