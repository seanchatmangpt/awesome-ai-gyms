# DFCM Generative Sequence

The pattern language is a graph, not a checklist. This chapter gives a high-information default route while preserving alternate lawful paths.

## Default spine

1. **Preserve the graph before choosing.** Start with [P63 · Combinatorial Maximalism](patterns/self-manufacturing/63-combinatorial-maximalism.md), [P09 · Possibility Registry](patterns/discovery-composition/09-possibility-registry.md), and [P11 · Candidate Is Not Capability](patterns/discovery-composition/11-candidate-is-not-capability.md).
2. **Fence the exact world and subject.** Apply [P01 · Bounded World](patterns/foundations/01-bounded-world.md), [P02 · Canonical Subject](patterns/foundations/02-canonical-subject.md), and [P03 · Explicit Observation](patterns/foundations/03-explicit-observation.md).
3. **State the falsifier and hard constraints.** Apply [P23 · Falsifier First](patterns/planning-selection/23-falsifier-first.md) and [P22 · Constraint Fence](patterns/planning-selection/22-constraint-fence.md).
4. **Create machine-checkable semantics.** Apply [P25 · Ontology First](patterns/manufacture/25-ontology-first.md) and, where planners need narrower representations, [P19 · Planning Projection](patterns/planning-selection/19-planning-projection.md).
5. **Explore without accidental consequence.** Apply [P17 · Planner League](patterns/planning-selection/17-planner-league.md), [P20 · Multiple Formulations](patterns/planning-selection/20-multiple-formulations.md), and [P21 · Partial Order Before Total Order](patterns/planning-selection/21-partial-order-before-total-order.md).
6. **Keep selection powerless.** Apply [P24 · Selection Is Not Authorization](patterns/planning-selection/24-selection-is-not-authorization.md), [P04 · Admission Before Action](patterns/foundations/04-admission-before-action.md), and [P05 · Authority Boundary](patterns/foundations/05-authority-boundary.md).
7. **Manufacture deterministically.** Apply [P26 · One Pack, One Manufacturing Boundary](patterns/manufacture/26-one-pack-one-manufacturing-boundary.md), [P30 · Deterministic Projection](patterns/manufacture/30-deterministic-projection.md), and [P31 · Generated Is Canonical](patterns/manufacture/31-generated-is-canonical.md).
8. **Cross DO through one broker.** Apply [P06 · Consequence Boundary](patterns/foundations/06-consequence-boundary.md), [P33 · BRCE Is the Only DO](patterns/execution-safety/33-brce-is-the-only-do.md), [P34 · Zero Unreceipted Actuation](patterns/execution-safety/34-zero-unreceipted-actuation.md), and [P40 · Independent Postcondition](patterns/execution-safety/40-independent-postcondition.md).
9. **Bind execution to evidence.** Apply [P07 · Receipt](patterns/foundations/07-receipt.md), [P44 · Exact Subject Binding](patterns/evidence-learning/44-exact-subject-binding.md), [P45 · Receipt DAG](patterns/evidence-learning/45-receipt-dag.md), and [P46 · Replay Equivalence](patterns/evidence-learning/46-replay-equivalence.md).
10. **Turn failure into topology and law.** Apply [P39 · Failure Is Topology](patterns/execution-safety/39-failure-is-topology.md) and [P47 · Failure Becomes Law](patterns/evidence-learning/47-failure-becomes-law.md).
11. **Advance only at the evidence floor.** Apply [P49 · Five-by-Seven Maturity](patterns/enterprise-operations/49-five-by-seven-maturity.md), [P50 · Minimum Plane Governs](patterns/enterprise-operations/50-minimum-plane-governs.md), and [P55 · Release Crown](patterns/enterprise-operations/55-release-crown.md).
12. **Prove manufacturing closure.** End with [P57 · Empty Repo Crown](patterns/self-manufacturing/57-empty-repo-crown.md), [P58 · Delete and Regenerate](patterns/self-manufacturing/58-delete-and-regenerate.md), [P59 · GgenGym](patterns/self-manufacturing/59-ggengym.md), and [P64 · Closed Causal Loop](patterns/self-manufacturing/64-closed-causal-loop.md).

## Alternate lawful entry routes

| Goal | Enter through | Then follow |
|---|---|---|
| Integrate an external benchmark | [P10 · Provenance Lock](patterns/discovery-composition/10-provenance-lock.md) | P12 → P15 → P01 → P32 |
| Create a reusable ggen pack | [P27 · ggen-create Discovers Pack Law](patterns/manufacture/27-ggen-create-discovers-pack-law.md) | P26 → P28 → P29 → P57 |
| Harden an execution path | [P35 · Tool Call Is Intent](patterns/execution-safety/35-tool-call-is-intent.md) | P04 → P05 → P33 → P34 → P40 |
| Repair a recurring failure | [P39 · Failure Is Topology](patterns/execution-safety/39-failure-is-topology.md) | P23 → P47 → P62 |
| Prepare an enterprise release | [P49 · Five-by-Seven Maturity](patterns/enterprise-operations/49-five-by-seven-maturity.md) | P50 → P51 → P52 → P54 → P55 |

These routes are projections over the same pattern graph. DFCM permits a different route whenever the omitted obligations are already evidenced and the alternative preserves the same authority and consequence boundaries.
