# I · Foundations { #family-foundations }

The smallest invariants that make a gym a bounded, evidentiary system rather than a demo.

This family establishes the fences that every later composition depends on. DFCM preserves a large possibility graph only because world, subject, observation, authority, consequence, receipt, and replay boundaries remain explicit.

## DFCM composition rule

Do not treat this list as a total order. These patterns form the admission and evidence substrate for every later family. Preserve all reversible construction and selection upstream; require these fences before consequential DO.
