# P64 · Closed Causal Loop { #p64 }

> **Family:** [VIII · Self-Manufacturing Ecosystem](../self-manufacturing.md)  
> **Confidence:** ★★★  
> **Canonical ID:** `P64`

## Context

The ecosystem has discovery, planning, manufacture, execution, evidence, and learning components.

## Problem

If these components exchange prose or ad hoc files rather than shared identities and receipts, failures cannot improve future manufacture and selection.

## Forces

- Different systems optimize different concerns.
- Loops can amplify bad inference.
- Canonical state and behavioral evidence have different roles.

## Resolution

**Close the loop: admitted knowledge graph → executable world → observed event evidence → analysis → hypothesis/intervention portfolio → bounded experiment → consequence → verification → receipt → learned law → deterministic manufacture → new world state. Keep observation, inference, authority, and actuation typed throughout.**

## Consequences

The ecosystem becomes self-improving without making the model or planner the authority source.

## Falsifier

A failure or successful experiment cannot be traced into a changed selector, constraint, pack, verifier, or manufacturing law.

## Evidence contract

- [ ] shared subject identities
- [ ] event/receipt spine
- [ ] explicit learning transition
- [ ] updated law/projection
- [ ] subsequent verification
