# P57 · Empty Repo Crown { #p57 }

> **Family:** [VIII · Self-Manufacturing Ecosystem](../self-manufacturing.md)  
> **Confidence:** ★★★  
> **Canonical ID:** `P57`

## Context

A manufacturing system claims it can create a complete project capability from admitted semantics and qualified packs.

## Problem

Success on a heavily prepared repository may merely prove hidden manual setup rather than autonomous manufacture.

## Forces

- Empty starts expose missing assumptions.
- Real projects contain legacy constraints.
- Bootstrap dependencies still need to come from somewhere.

## Resolution

**Use an intentionally empty consumer repository or directory as the crown world. From only admitted project semantics, resolved qualified packs, and pinned toolchain, manufacture the project and run its gym to behavioral standing.**

## Consequences

The demonstration measures manufacturing closure rather than template rendering.

## Falsifier

The empty-repo scenario requires hand-authored application/config/test glue after generation before the project gym can pass.

- [ ] empty baseline identity
- [ ] semantic input
- [ ] pack lock
- [ ] manufacture receipt
- [ ] project-gym ALIVE receipt
