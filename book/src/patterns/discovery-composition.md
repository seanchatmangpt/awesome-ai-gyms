# II · Discovery and Composition { #family-discovery-composition }

How to preserve a large ecosystem of candidates without converting discovery into authority.

DFCM starts here: discovery expands the possibility graph; provenance and compatibility edges constrain it without prematurely deleting lawful alternatives.

## DFCM composition rule

A discovered node remains `UNKNOWN` until an exact edge is evidenced. Failure removes or penalizes the failed edge; it does not erase the node or unrelated compositions.
